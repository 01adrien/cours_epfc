FLOW AUTHENTIFICATION:
    - L'utilisateur recoit un QR code.
    - L'utilisateur scanne le QR code sur le module caméra.
    - L'esp 32 fait une requete HTTP a l'app (avec la key du QR code + l'id de la serrure).
    - L'app interroge la DB pour le couple key / serrure.
    - L'esp 32 recoit réponse de l'app:
        - Access Granted, diode verte + esp 32 ouvre serrure.
        - Access Denied, diode rouge.
